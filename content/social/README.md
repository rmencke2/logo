# Social drafts

Copy-paste kits for posts that promote Influzer Insights without dumping the blog into a feed.

## Rules

- Disclose affiliation in the body (`we run influzer.ai`).
- One primary link in the post; extra links go in a first comment.
- On Reddit, **ask** before you lecture. A short setup + three sharp questions beats a how-to. Save the playbook for a later comment if people ask.
- Keep titles under 300 characters (Reddit limit).
